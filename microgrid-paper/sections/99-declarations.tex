\section*{Code and data availability}

The simulation platform and training scripts are available at \url{https://github.com/WeijiaTang/microgrid_sim}. The repository includes the IEEE33 case configuration, the shielded replay SAC implementation, the morphology-aware validation protocol, and result summaries. The reported P4 tables and figures are generated from trajectory summaries under \path{results/ieee33/network_stress/simple} and manuscript source-data CSV files under \path{microgrid-paper/figures/source_data}.

The IEEE 33-bus feeder topology is a standard test system available in the pandapower library. The repository contains 15-min network profiles for the IEEE33 case. These profiles are reconstructed and scaled from the project data layer, including load, photovoltaic, weather, and tariff/price traces. Source datasets used in constructing the data layer include residential load information from the Pecan Street Dataport, photovoltaic generation patterns derived with NREL's System Advisor Model workflow, and electricity-price traces based on CAISO market records. The network-stress regime modifications and battery-placement configuration are described in Section~\ref{sec:system_model}. Access to any third-party raw datasets remains subject to the corresponding provider terms.
